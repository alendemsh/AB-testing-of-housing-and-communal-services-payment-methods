# A/B-тест оплаты ЖКХ

EDA_ЖКХ.ipynb — выполненный Python-ноутбук с кодом, таблицами и графиками.
Разделы 1–11 — EDA, раздел 12 — статистические проверки, раздел 13 — рекомендация.
Основная проверка: перестановка групп по клиентам и кластерный bootstrap, 20 000 повторов каждого метода.
Оба исходных CSV должны лежать рядом с ноутбуком. Зависимости: pandas numpy matplotlib seaborn scipy jupyter.
Все кодовые ячейки выполнены последовательно. Результаты и графики сохранены.
